# 胃癌免疫敏感亚型 AI 预测 —— 给医学生看的说明

> 这个项目想用一张普通的病理切片（H&E），帮医生猜出某个胃癌病人**是不是适合做免疫治疗**。
> 下面用尽量少的专业术语讲清楚：这件事为什么有意义、现在做到哪一步了、**还差什么（尤其是你能帮上忙的部分）**。

---

## 一、这件事的临床意义（为什么值得做）

### 1. 免疫治疗对一部分胃癌特别有效，但得先"挑对人"

胃癌的免疫治疗（PD-1/PD-L1 抑制剂，比如纳武利尤单抗）不是对所有人都有效——**只有大约 15%–30% 的病人能从中获益**。给不敏感的病人用，既浪费钱、可能耽误治疗，还白挨副作用。所以**精准筛选"谁该上免疫治疗"**，是个真实的临床问题。

### 2. 谁敏感？两条分子线索

TCGA 2014 分型发现，有两类胃癌对免疫治疗特别敏感，合称**"免疫敏感亚型"**：

| 亚型 | 一句话解释 | 为什么敏感 |
|------|-----------|-----------|
| **MSI-H**（微卫星不稳定高） | 癌细胞 DNA"错字"修不好，突变越堆越多 | 突变多 → 免疫细胞容易认出来 → 免疫治疗见效 |
| **EBV+**（EB 病毒阳性） | 肿瘤里有 EB 病毒感染 | 病毒激活了局部免疫微环境 |

两者加起来约占胃癌的 **30%**。临床试验已经证实了它们的价值：
- **MSI-H** 胃癌对传统 5-FU 化疗反而"抵抗"（Pietrantonio, *JCO* 2019），但对新辅助免疫治疗反应极好——NEONIPIGA 研究（Andre, *JCO* 2023）里 dMMR/MSI-H 病人用 nivo+ipi，**病理完全缓解（pCR）率超过 60%**。
- **EBV+** 是另一条独立的免疫敏感路线。

### 3. 痛点：分子检测"够不着"

要知道一个病人是不是 MSI-H / EBV+，得做分子检测——PCR 测微卫星、IHC 测错配修复蛋白（MMR）、ISH 测 EBV。

问题在于：
- **基层医院做不了或做不好**，设备、试剂、判读能力都缺；
- **活检小样本失败率高**，取材不够就测不准；
- **慢、贵**，不是每个病人都能常规做。

但是有一样东西**几乎每个胃癌病人都有、且几乎零成本**——

> **H&E 病理切片**。病理科切下来染个色、显微镜下看形态，是诊断胃癌的最常规检查，人人都会做、人人都有片子。

### 4. 这个项目想做的事

> **能不能让 AI 看一眼 H&E 切片，就初步判断这个病人是不是"免疫敏感型"？**
>
> 如果可以，它就能当一个**零成本初筛工具**：
> AI 说"可能敏感"的病人 → 再去做分子检测确诊；
> AI 说"明显不敏感"的病人 → 可以先考虑别的方案，省下检测资源和时间。

这就是项目的全部立意。它**不替代分子检测**，而是**在分子检测之前加一道便宜、快速的筛**，把宝贵的分子检测资源留给最可能获益的人。

## 二、AI 到底做了什么（一句话 + 展开）

**一句话**：把一张全切片图像（WSI）切成上万个小区块，用 AI 提取每个区块的形态特征，加权汇总后判断这个病人的免疫敏感概率，再由一个"Agent"写出带形态学解释的报告。

### 模型面板（每个模型解决一个临床问题）

| 模型 | 临床任务 | 输入 | AUC | 临床含义 |
|------|---------|------|-----|---------|
| **M1** | 免疫敏感(MSI∪EBV) vs 不敏感 | H&E 切片特征 | **0.897** | 主预测器，决定"筛不筛" |
| **M2** | MSI-H vs MSS | 同上 | **0.906** | 精确判 MSI |
| **M3** | EBV+ vs EBV- | 同上 | 0.738 | 精确判 EBV |
| **M4** | 四亚型(EBV/MSI/GS/CIN) | 同上 | macro 0.859 | 分子分型全景 |
| **M5** | 免疫敏感（**仅临床信息**） | 年龄/性别/Lauren/分期 | 0.620 | 对照基线，证明图像价值 |
| **M6** | 生存预后 | 切片特征 | C-index 0.552 | 次要终点 |
| **Agent** | 编排+解释 | 上述全部+切片图 | — | 交叉验证 + 可解释报告 |

### 两个关键数字说明了什么

1. **M1 免疫敏感 AUC = 0.897**（95% CI 0.855–0.940）—— 高于文献同类工作（Kather 2019 的 0.81），说明"看切片猜免疫敏感"这件事在 TCGA 数据上是可行的。
2. **图像(0.897) vs 仅临床(0.620) = 差了 0.277** —— 这证明切片里确实藏着临床信息之外的有用形态学信号，不是靠年龄分期这种"已知变量"在蒙。

### Agent 报告长什么样

Agent 不改预测结果（最终判断永远是 M1 说了算），它只做**解释和交叉验证**：

- 自动看 M1、M2、M3 是否同向——多模型一致 → 高置信；冲突或边界 → 低置信；
- 看切片的形态聚类图，提取"淋巴细胞（TIL）密度、是否聚集、是否在肿瘤边界浸润"等证据；
- 输出一份病理风格报告，并**指明该做什么验证**（比如"建议做 MMR 蛋白 IHC + EBER-ISH 确认"）。

举一个真实边界病例（TCGA-BR-7703）：
> M1 判敏感(0.589) 但 M2(MSI 0.141)、M3(EBV 0) 冲突 → Agent 给低置信，报告写："支持免疫微环境激活，但 MSI/EBV 证据冲突，**强烈建议行 MMR 蛋白及 EBER-ISH 检测**以确认。"

这种"AI 给概率 + 明确指向下一步该查什么"的报告，正是为了让临床医生敢用、敢信。

**最大的局限（必须承认）：现在所有结果都来自 TCGA 这一个数据集。**

- TCGA 以**西方人群**为主；
- 模型是在"自己内部互相验证"（交叉验证），AUC 容易偏乐观；
- **还没有在任何独立的外部队列上测过**。

这是论文能不能发到好期刊（IF 8–15）的硬门槛，也是接下来最需要补的事。

## 四、还需要医学生做什么（重点）

下面这些事，**计算机同学做不了，必须有医学背景的人参与**。按重要性从高到低排。

### 🔴 必做（决定能不能发表）

#### 1. 拿一个外部胃癌队列来做独立验证
这是论文能不能发的**关键门槛**。需要：
- 一个**独立的**胃癌 H&E 切片队列（不是 TCGA 里的），最好含亚洲人群；
- 候选：**ACRG**（韩国亚洲人群队列）、韩国 SNU 队列，或**本院胃癌队列**；
- 每例都要有 MSI/EBV 的分子检测"金标准"标签；
- 我们拿训练好的模型去预测，看在外部队列上的 AUC、敏感度、特异度。

**医学生能做**：找队列、对接数据获取（伦理审批/数据使用协议）、核对分子标签质量。这是纯医学侧的活。

#### 2. 用 IHC 验证 Agent 报告里说的"形态"
Agent 报告会写"这个区域 TIL 密集聚集""淋巴细胞在肿瘤-基质界面浸润"。这些是**AI 的描述**，需要病理验证它说的对不对：
- 对 Agent 标出来的 TIL-dense 区域，做**连续切片的 CD3/CD8 IHC 染色**；
- 人工计数 TIL，和 Agent 的描述做相关性（Spearman）；
- 量化"AI 形态描述 vs IHC 计数"的一致性。

**医学生能做**：IHC 染色、TIL 计数、形态模式复核、和病理科对接盲评。这是最能体现医学贡献的部分——**证明 AI 不是在瞎说**。

### 🟡 建议做（增强说服力）

#### 3. 分子-图像相关性
证明"图像里看到的免疫浸润"和"分子层面的免疫激活"是一回事：
- 取 TCGA 的 mRNA 免疫签名（CD8A / CXCL9 / CXCL10，细胞毒 T 细胞标志）；
- 和图像提取的 TIL 特征做相关分析；
- 如果图像 TIL 高 ↔ 分子免疫签名高，说明 AI 抓到的形态确实有生物学意义。

#### 4. 生存分层（次要终点）
用 M1 预测的"敏感/不敏感"给病人分组，画 Kaplan-Meier 生存曲线，看预测有没有预后价值。

#### 5. POLE 敏感性分析
主分析应排除 POLE 突变型（约 10 例，和 MSI 微环境不同），附录补含 POLE 的结果。需要从分子数据里识别 POLE 病例。

### 🟢 本院数据衔接（未来工作，本文不做）

- 本院**新辅助治疗胃癌队列**：治疗前活检 + 治疗后手术标本配对；
- 直接预测 **pCR / TRG**（病理完全缓解 / 肿瘤退缩分级）—— 这才是临床真正想直接预测的硬终点；
- 目标期刊：Modern Pathology / NPJ Precision Oncology。

## 一句话总结

> 我们证明了"用普通 H&E 切片初筛胃癌免疫敏感亚型"在 TCGA 上可行（AUC 0.90）。
> 但要让它真正进临床、发好论文，**还需要医学生帮我们做两件事：找一个外部队列验证它准不准，以及用 IHC 验证 AI 写的形态报告是不是真的**。
> 计算机能造出模型，但"这模型说的是不是医学事实"——只有医学背景的人能回答。
