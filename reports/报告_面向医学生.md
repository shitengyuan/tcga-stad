## 一、研究背景与临床意义

### 临床问题

胃癌是常见恶性肿瘤，新辅助/辅助治疗选择有限。**免疫治疗（PD-1/PD-L1 抑制剂）**对部分胃癌患者显著获益，但仅约 15-30% 患者有效，需精准筛选获益人群。

**免疫治疗敏感的胃癌分子亚型**（TCGA 2014 分型）：
- **MSI-H（微卫星不稳定高）**：DNA 错配修复缺陷，高突变负荷。Pietrantonio JCO 2019 meta 分析显示 MSI-H 患者对传统 5-FU 化疗抵抗；NEONIPIGA（Andre JCO 2023）显示 dMMR/MSI-H 新辅助 nivo+ipi pCR 率 60%+。
- **EBV+（EB 病毒阳性）**：PD-L1 高表达，CD8 TIL 丰富，免疫微环境活跃。
- 两者合称"免疫敏感亚型"，约占胃癌 30%。

**痛点**：MSI/EBV 检测需分子手段（PCR/IHC/ISH），基层医院不普及，活检小样本失败率高。**H&E 切片几乎人人都有**——若能从 H&E 预测免疫敏感亚型，可作零成本初筛，阳性再做分子确诊。

### 研究目标

用 AI 从诊断 H&E 切片预测胃癌免疫敏感亚型，并产出**可被 IHC/分子验证的形态学解释**，辅助临床决策。

## 二、AI 模型做了什么（任务清单）

我们训练了一个**多任务模型面板**，每个模型解决一个临床问题：

| 模型 | 临床任务 | 输入 | 输出 | AUC | 临床用途 |
|------|---------|------|------|-----|---------|
| **M1** | 免疫敏感(MSI∪EBV) vs 不敏感 | H&E 切片图像特征 | 敏感概率 0-1 | **0.897** | 主预测器，初筛免疫治疗 |
| **M2** | MSI-H vs MSS | 同上 | MSI-H 概率 | **0.906** | 精确判 MSI |
| **M3** | EBV+ vs EBV- | 同上 | EBV+ 概率 | 0.738 | 精确判 EBV |
| **M4** | 四亚型(EBV/MSI/GS/CIN) | 同上 | 四类各概率 | macro 0.859 | 分子分型全景 |
| **M5** | 免疫敏感(仅临床) | 年龄/性别/Lauren/分期 | 敏感概率 | 0.620 | 消融基线 |
| **M6** | 生存预后 | 图像特征 | 风险分 | C-index 0.552 | 次要终点 |
| **Agent** | 编排+解释 | 上述全部 + 切片图 | 病理报告 | — | 交叉验证 + 可解释报告 |

**关键数字**：M1 免疫敏感 AUC 0.897（CI 0.855-0.940），远超 Kather 2019 的 0.81；图像(M1 0.897) vs 临床(M5 0.620) = +0.277，证明 H&E 图像特征价值巨大。

### 输入输出详解（以 M1 为例）

- **输入**：一张 H&E WSI（全切片图像），AI 先切成 ~1.3 万个小块（patch，256×256 像素），每个 patch 用 UNI2-h 模型编码成 1536 维特征向量。
- **过程**：ABMIL 模型给每个 patch 算注意力权重，加权汇总成一个病人级向量，再分类。
- **输出**：免疫敏感概率（0-1），≥0.5 判敏感。
- **解释**：Agent 额外看切片的形态聚类图，提取 TIL（肿瘤浸润淋巴细胞）密度/聚集/界面浸润证据，写报告。

## 三、具体 Case 示例

> 以下为 Agent 面板对 3 个代表性病例的真实输出（模型：M1-M5 五模型面板 + DeepSeek-v3 生成报告）

### Case 1：敏感高置信（EBV+）— 模型间部分冲突

**TCGA-VQ-AA69**（STAD_EBV 亚型）

| 模型 | 预测概率 | 判断 |
|------|---------|------|
| M1 免疫敏感 | 1.000 | 敏感 |
| M2 MSI | 0.191 | 不敏感 |
| M3 EBV | **0.984** | EBV+ |
| M4 四亚型 | 0.904 | — |
| M5 临床 | 0.118 | 不敏感 |

- **Agent 判断**：置信 low（M1 与 M3 一致判敏感，但 M2/M5 冲突）
- **报告**："M1主预测免疫敏感(1.000)，与M3(EBV 0.984)高度一致，支持EBV相关免疫敏感表型。M2(MSI 0.191)存在冲突。建议行MMR蛋白及EBER-ISH以验证EBV状态。"
- **医学验证锚点**：报告指向 EBV → 做 EBER-ISH 确认

### Case 2：不敏感高置信 — 多模型一致

**TCGA-VQ-AA6K**（STAD_CIN，印戒细胞型）

| 模型 | 预测概率 | 判断 |
|------|---------|------|
| M1 免疫敏感 | 0.000 | 不敏感 |
| M2 MSI | 0.000 | 不敏感 |
| M3 EBV | 0.000 | 不敏感 |
| M4 四亚型 | 0.000 | — |
| M5 临床 | 0.328 | 不敏感 |

- **Agent 判断**：置信 high（M1/M2/M3 全一致判不敏感）
- **报告**："多模型一致(M1/M2/M3概率均0.0)支持免疫不敏感表型。形态学为印戒细胞型,CIN亚型,缺乏MSI/EBV相关特征。建议IHC验证MMR蛋白及EBER-ISH以排除。"
- **医学验证锚点**：多模型一致 + CIN 亚型印证

### Case 3：边界病例 — 模型间冲突，需 IHC 确认

**TCGA-BR-7703**（STAD_MSI，M1 概率 0.589）

| 模型 | 预测概率 | 判断 |
|------|---------|------|
| M1 免疫敏感 | 0.589 | 敏感（边界）|
| M2 MSI | 0.141 | 不敏感 |
| M3 EBV | 0.000 | 不敏感 |
| M4 四亚型 | 0.930 | — |
| M5 临床 | 0.476 | 不敏感 |

- **Agent 判断**：置信 low（M1 边界 + M2/M3 冲突）
- **报告**："M1主预测免疫敏感(0.589)与M4(0.93)一致，支持免疫微环境激活。M2/M3低概率冲突，临床STAD_MSI需进一步验证。建议行MMR蛋白及EBER-ISH检测以确认MSI/EBV状态，辅助免疫治疗决策。"
- **医学验证锚点**：边界 + 冲突 → 强烈建议 MMR+EBER-ISH 双重确认

### Case 示例小结

Agent 的价值体现：
1. **模型一致性分析**：自动判断 M1 与 M2/M3 是否同向，识别冲突
2. **置信度分级**：多模型一致→high，冲突/边界→low
3. **IHC 验证建议**：根据冲突类型建议 MMR/EBER-ISH/both
4. **不改预测**：最终判断恒等于 M1，agent 只做解释，零指标风险

## 四、整体流程（端到端）

```
病人 H&E 切片
    ↓ UNI2-h 提特征 (patch 级 1536 维)
    ↓
模型面板预测:
  M1 免疫敏感 → 主判断
  M2 MSI / M3 EBV / M4 四亚型 → 交叉验证
  M5 临床 / M6 生存 → 辅助
    ↓
Agent 编排 (GLM-5.2 + glm-4v-plus):
  ① 规则判断模型一致性 (M1 vs M2/M3)
  ② 视觉提取 TIL 形态证据
  ③ 综合写病理报告
    ↓
输出: 免疫敏感预测 + 可IHC验证的形态学报告
    ↓
临床应用: AI 初筛 → 阳性/不确定病例做分子检测(IHC/PCR/ISH)确诊 → 治疗决策
```
