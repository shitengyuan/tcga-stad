## 5. Attention 全 patch 可视化

更新文件：`generate_visual_evidence_package.py`

新增能力：

- `--all_patches_attention`：每张 h5 的所有 patch 都参与 attention 热力图绘制；
- `--all_feature_slides`：遍历 feature 目录下每个 `.h5`，用于全部切片批量出图；
- `--out_dir`：可把全 patch 结果单独输出，避免覆盖原来的抽样证据包；
- manifest 增加 `n_patches_total`、`n_patches_attention_plotted`、`attention_patch_sampling`，用于核查是否真正绘制了全部 patch。

推荐命令：

```bash
cd /gpfsdata/home/shitengyuan/shitengyuan_lustre/medical/tcga-stad
python generate_visual_evidence_package.py \
  --device cuda:0 \
  --all_patches_attention \
  --out_dir results/visual_evidence_package_all_patches
```

如果要对当前 TCGA feature 目录的全部 400 个 h5 切片生成全 patch attention：

```bash
python generate_visual_evidence_package.py \
  --device cuda:0 \
  --all_patches_attention \
  --all_feature_slides \
  --feature_dir tcga_stad_uni2h/TCGA-STAD/features \
  --out_dir results/visual_evidence_package_all_feature_slides_all_patches
```

如果当前节点没有 GPU，也可以用 CPU：

```bash
python generate_visual_evidence_package.py \
  --device cpu \
  --all_patches_attention \
  --out_dir results/visual_evidence_package_all_patches
```

注意：目前输出仍是坐标级 attention heatmap，不是叠加在真实 WSI 缩略图上的病理热力图。cluster 的 TIL/肿瘤/间质/坏死命名仍需代表 patch 渲染和病理医生盲评后才能作为形态学结论。
