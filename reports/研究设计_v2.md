# 胃癌 H&E → 免疫敏感亚型预测 研究设计 v2

> **一句话定位**：用 UNI2-h patch 特征 + ABMIL + GLM5.2 agent，从诊断 H&E 预测胃癌"免疫治疗敏感亚型"（MSI-H ∪ EBV+），融合常规临床特征，并用分子数据做生物学验证，为后续本院新辅助治疗队列研究铺路。

## §1 研究问题与定位

| 项 | 内容 |
|----|------|
| **核心问题** | 能否仅用诊断 H&E 切片 + 常规临床信息，通过 agentic 病理框架预测胃癌免疫治疗敏感亚型，并给出可被分子/IHC 验证的解释？ |
| **临床意义** | MSI-H/EBV+ 胃癌对新辅助免疫治疗高度敏感（NEONIPIGA pCR 60%+），但分子检测基层不普及。AI 提供零成本初筛工具。 |
| **定位** | 概念验证 + 方法学奠基；为后续本院新辅助队列（直接预测 pCR/TRG）铺路 |
| **目标期刊** | 冲刺 npj Digital Medicine / Cell Reports Medicine（IF 8-15）；稳妥回落 Cancer Med |
| **诚实声明** | TCGA 单中心偏倚（西方人群为主），需外部队列独立验证；400 样本需报 bootstrap CI |

### 1.1 临床故事
- **MSI-H 胃癌对化疗抵抗** — Pietrantonio JCO 2019 meta-analysis：MSI-H 患者围手术期 5-FU 化疗不获益甚至受害
- **MSI-H/EBV+ 胃癌对免疫治疗高度敏感** — NEONIPIGA（Andre JCO 2023）dMMR/MSI-H 新辅助 nivo+ipi pCR 60%+；CheckMate-649、KEYNOTE-585/859 亚组确认 MSI-H 获益；EBV+ 是另一免疫敏感亚型
- **临床痛点** — MSI/EBV 检测需 IHC(MMR)/PCR/EBV-ISH，基层不普及，活检小样本失败率高
- **AI 切入口** — H&E + 常规病历普遍存在，AI 模型作为初筛，阳性病例再做分子检测确认

## §2 数据策略

### 2.1 数据来源

| 数据 | 渠道 | 状态 |
|------|------|------|
| TCGA-STAD WSI 特征 (UNI2-h 1536d) | HF `W8Yi/tcga-wsi-uni2h-features` | ✅ 已下载至 `tcga_stad_uni2h/` |
| 临床信息 (88 属性) + 分子亚型 + MSI/EBV/Lauren + 生存 | cBioPortal `stad_tcga` | 待拉取 |
| somatic mutation (MAF) | cBioPortal / GDC | 待拉取（用于 POLE 排除） |
| 分子组学 (mRNA/甲基化/RPPA) | cBioPortal | 待拉取（仅验证用） |
| 外部验证队列 (ACRG / 韩国 WSI) | 公开 / GDC | 待确认 |

### 2.2 样本与标签

**400 slide ↔ ~440 TCGA-STAD patient**，slide barcode 前 12 位 = patient_id 对齐。

**标签构造**（免疫敏感二分类）：
- **正例（免疫敏感）** = MSI-H ∪ EBV+
- **负例（非敏感）** = 其余（含 MSI-L/MSS、GS、CIN）
- **POLE 排除**：从 MAF 找 POLE exonuclease domain mutation 的样本，主分析排除（~10 例），附录补敏感性分析
- 预期正例 ~95-100，负例 ~300，1:3 配比，样本量充足

**纳入标准**（沿用 v1 §2.2）：
- diagnostic_slide（已由特征提取 pipeline 保证）
- 有 MSI/EBV 标签
- **treatment-naive**（用 `HISTORY_NEOADJUVANT_TRTYN` 字段排除新辅助治疗病例）
- OS 随访可用于生存分析

### 2.3 数据结构（已就位的 UNI2-h 特征）

每个 `.h5`（per slide）：
- `features`: `(1, N, 1536)` float32 — UNI2-h patch 特征（N=patch 数，中位 13167）
- `coords_patching`: `(N, 2)` int64 — patch 坐标（空间分析用，去掉外层 batch 维）
- `annots`: `(1, N, 1)` int64 — patch 标注
- 400 slide 共 520 万 patch，patch 数范围 463–34829

## §3 方法：ML 骨干 + Agent 层（多模态）

### 3.1 ⚠️ 方法学红线：分子特征不做输入（避免数据泄露）

> **MSI 状态本身就是分子检测（PCR/IHC）的产物。** TMB、突变计数、甲基化聚类都与 MSI 高度相关（MSI-H=高突变）。**用 TMB 预测 MSI 是循环论证**——AUC 会虚高到 0.95+ 但毫无临床意义（没有替代任何分子检测）。

特征分层：

| 层 | 内容 | 角色 | 能否做输入 |
|----|------|------|-----------|
| **A 图像** | UNI2-h patch + ABMIL + agent 空间特征 | 主输入 | ✅ 临床可部署核心 |
| **B 临床** | age, sex, Lauren, stage, site, H.pylori 等 | 辅助输入 | ✅ 常规可得，非分子检测，无泄露 |
| **C 分子** | TMB, 突变, CNV, mRNA, 甲基化, RPPA | **验证/解释** | ❌ 不做输入 |

### 3.2 整体架构

```
                        ┌─ UNI2-h patch features (1536d) + coords ─┐
                        │                                           │
           ┌────────────▼──────────────┐              ┌─────────────▼──────────────┐
           │  ML 骨干（拼 SOTA AUC）    │              │  Agent 层（GLM5.2，拼解释） │
           │  ABMIL attention 聚合     │              │  tool-calling 空间推理       │
           │  → patient-level prob     │              │  → 可解释空间特征 + 报告     │
           └────────────┬──────────────┘              └─────────────┬──────────────┘
                        │                                           │
                        └─► 图像向量 ◄──────────────────────────────┘
                                          │
                       临床特征 (age/sex/Lauren/stage/site/H.pylori)
                                          │
                                   轻量融合 (LR/XGBoost)
                                          │
                          最终预测 + 自然语言病理报告
```

### 3.3 输入侧特征

**A. 图像特征**
- UNI2-h 1536d → **ABMIL**（attention-based MIL, Ilse 2018）聚合 520 万 patch → patient 向量
- UNI2-h 是 2024 foundation model，比 Kather ResNet18 强一代 → 预期 AUC 0.85-0.90，超 Kather 0.81
- 对标文献综述 [T3-27] Virchow/UNI 路线，正面回应"为何不用基础模型"——**就在用**

**A+. agent 派生空间特征**（研究设计 v1 §3.2 升级版）
- 先对 patch 特征无监督聚类（K=5-8）→ tumor/stroma/lymphocyte/necrosis 形态原型（Kather 工作流标准动作）
- agent 通过 tool-calling 主动决定算哪些空间统计：
  - `compute_density(region, cluster)` — 区域内某形态原型密度
  - `ripley_K(cluster)` — 淋巴细胞聚集度
  - `boundary_proximity(cluster)` — TIL 到肿瘤-基质边界距离
  - `summarize_region(bbox)` — 调取 overlay PNG 给 agent 看（vision）
- 把研究设计 v1 的"硬编码 HoVer-Net 特征"升级为"agent 假设驱动特征工程"——novel
- 对标 [T1-5] Zhang 2025（HoVer-Net 核特征）+ [T2-12] Zhang B 2021（空间淋巴细胞模式）

**B. 临床特征**（新增，填补 Zhang 2025 自承的 future work）

| 字段 (cBioPortal) | 用途 |
|-------------------|------|
| `AGE`, `SEX` | 人口学 |
| `HISTOLOGICAL_DIAGNOSIS` / Lauren 分型 | 胃癌最重要临床分型，与 MSI/EBV 分布强相关 |
| `AJCC_PATHOLOGIC_TUMOR_STAGE`, `LYMPH_NODE_EXAMINED_COUNT` | 分期 |
| `PRIMARY_SITE_PATIENT` / `SITE_OF_TUMOR_TISSUE` | 贲门/胃体/幽门，EBV 好发贲门 |
| `H_PYLORI_INFECTION` | H.pylori 与 MSI 关联 |
| `HISTORY_NEOADJUVANT_TRTYN` | **排除新辅助治疗病例（纳入标准）** |

> **关键 novelty**：胃癌 MSI/EBV 这条赛道几乎所有 SOTA（Kather/Muti/Wang/Hinata/Zhang2025）都是纯 H&E。Zhang 2025 明确把"整合多组学"列为 future work。**首个 agentic + 图像+临床多模态** = 我们的差异化。

### 3.4 Agent 层（GLM5.2）做三件事
1. **假设驱动特征工程**：agent 根据文献（Crohn 样反应、TIL 边界浸润是 MSI 形态标志）主动决定算哪些空间统计 → 可解释特征向量
2. **难例二意见**：ABMIL 低置信度/边界病例，agent 看 overlay PNG 给第二预测
3. **报告生成**：写病理风格报告，指名具体区域和模式

### 3.5 融合与消融
- 图像向量 ⊕ 临床 one-hot/数值 → LR/XGBoost 出最终预测
- **消融表**（论文必须）：
  - 仅图像（UNI2-h+ABMIL）
  - 仅临床
  - 图像 + 临床
  - 图像 + 临床 + agent 空间特征
- **诚实定位**：agent 单独大概率打不过 ABMIL 的 AUC；其价值是可解释性 + 生物标志物发现 + 临床转化。SOTA 由"UNI2-h+ABMIL 骨干"扛，论文按此诚实写，不吹 agent 提 AUC。

## §4 SOTA 对标

| 对比对象 | 方法 | STAD MSI AUC | 我们的预期 |
|---------|------|-------------|-----------|
| [T1-1] Kather 2019 | ResNet18 + 均值聚合 | 0.81 | — |
| [T1-5] Zhang 2025 | CLAM ResNet50 + HoVer-Net 核特征 | ~0.85 | — |
| **我们** | **UNI2-h (FM) + ABMIL + agent 空间特征 + 临床** | — | **0.85-0.90** |

UNI2-h 比 ResNet18/HoVer-Net 特征更强，ABMIL 比均值聚合强——两个升级叠加超 0.81 合理。即使打平 Zhang 2025，**agent 可解释性 + 多模态 + 临床验证**是差异化。

## §5 验证侧（分子数据不做输入，做生物学说服力）

IF 8-15 的关键——让医学同学有抓手，让审稿人信服图像特征有生物学意义：

| 图像特征 | 对应分子验证 | 方法 |
|---------|------------|------|
| agent 标的 TIL-dense 区 | **CD8A/CXCL9/CXCL10 mRNA**（细胞毒 T 细胞签名） | Spearman 相关，证明图像-TIL ↔ 分子免疫浸润 |
| 预测的免疫敏感 | MSI 相关甲基化签名 | 一致性检验 |
| 形态聚类簇 | EBV 特征表达（EBV-CIMP） | 簇 vs 分子亚型关联 |
| 预测分层 | OS/DFS 生存 | KM + Cox（次要终点，临床效用） |

### 医学同学验证锚点
- CD3/CD8 IHC 验证 agent 标的 TIL-dense 边界区
- 本院胃癌队列复现"淋巴细胞包绕肿瘤巢"模式
- 边界病例做 MMR IHC/PCR/EBV-ISH 确认
- 病理科盲评 agent 报告 vs 真实报告（kappa 一致性）

## §6 评估规范（不可省，否则被审稿人秒杀）

1. **Site-stratified CV**（[T3-26] Howard 2021）—— TCGA barcode 第 2 段 = 医院，同院不跨 train/val
2. **Bootstrap 1000× 95% CI** —— 400 样本必须报置信区间
3. **外部验证** —— ACRG/韩国队列独立测试（决定能否冲 IF 8+）
4. **POLE 处理**（[T5-34] Hwang 2021）—— 主分析排除，敏感性分析
5. **Limitation 预答辩**：
   - FM 选择：为何 UNI2-h 非 Virchow
   - SSL：DeepSMILE [T3-22] 为何不用
   - 样本量 + 单中心偏倚
   - 分子特征不做输入的泄露考量（方法学亮点，不是短板）

## §8 实施路线（里程碑驱动）

| 步 | 任务 | 关键产出 | 风险 |
|----|------|---------|------|
| 1 | 拉 cBioPortal 临床+标签 + MAF，与 400 slide 对齐 | `clinical.csv`，MSI/EBV/POLE 分布 | POLE 识别需 MAF |
| 2 | 写 h5 特征加载器（features/coords，按 patient_id） | `load_features.py` | 无 |
| 3 | **ABMIL baseline** + site-stratified CV | 首个 AUC（里程碑：≥0.85 故事立住） | 若 <0.75 需诊断 |
| 4 | 临床特征融合 + 消融表 | 图像/临床/融合对比 | 无 |
| 5 | 形态聚类 + agent 工具原型 | agent 空间特征 | GLM5.2 工具调用工程量 |
| 6 | 分子验证（mRNA 免疫签名相关） | 生物学说服力 | mRNA 数据对齐 |
| 7 | 外部验证队列获取 + 测试 | 决定 IF 档位 | 队列获取最不确定，早启动 |

**第 3 步是关键里程碑**：ABMIL 单独能否打 0.85+ 决定故事能否立住。若只 0.75，先诊断是特征还是聚合问题，再谈 agent。
