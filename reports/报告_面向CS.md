## 一、任务是什么（一句话 + 展开）

**一句话**：用 AI 看胃癌的病理切片图（H&E 染色），预测这个病人是不是"免疫治疗敏感型"，好帮医生决定要不要上免疫治疗。

### 高中生物版背景

- **胃癌**：胃里长恶性肿瘤。治疗手段有手术、化疗、免疫治疗。
- **免疫治疗**：一种新疗法，激活病人自己的免疫细胞去杀肿瘤。效果好、副作用相对小，但**只对一部分人有效**。
- **H&E 切片**：病理科把切下来的肿瘤组织做成极薄的玻璃片，用两种染料（苏木精 H、伊红 E）染色，在显微镜下看细胞形态。这是医院最常规的病理检查，几乎每个病人都有。
- **"免疫敏感型"**：研究发现，有两类胃癌对免疫治疗特别敏感：
  - **MSI-H**（微卫星不稳定高）：癌细胞 DNA 修不好错，突变多，免疫细胞容易认出它。
  - **EBV+**（EB 病毒感染）：EB 病毒感染的胃癌，免疫微环境活跃。
  - 这两类加起来约占胃癌 30%，**该用免疫治疗**。
- **痛点**：要知道是不是 MSI-H/EBV+，得做分子检测（PCR/IHC/ISH），贵、慢、基层做不了。但 H&E 切片**人人都有**。所以：**能不能用 AI 看 H&E 切片，猜出是不是免疫敏感？** 这就是我们要做的事。

### 我们的预测任务（5 个模型，1 个面板）

| 模型 | 任务 | 输入 | 输出 |
|------|------|------|------|
| M1 | 免疫敏感(MSI∪EBV) vs 不敏感 | H&E 切片图像特征 | 敏感/不敏感 概率 |
| M2 | MSI-H vs MSS | 同上 | MSI-H 概率 |
| M3 | EBV+ vs EBV- | 同上 | EBV+ 概率 |
| M4 | 四亚型(EBV/MSI/GS/CIN) | 同上 | 四类各概率 |
| M5 | 免疫敏感(仅临床) | 年龄/性别/分期/分型 | 敏感概率 |
| M6 | 生存预后 | 图像特征 | 风险分(越高越差) |
| Agent | 编排+解释 | 上述全部+切片图 | 报告 |

M1 是主预测器，M2-M6 是辅助（让 Agent 能交叉验证 + 出更全的报告）。

## 二、AI 模型是什么（详细讲）

### 核心：UNI2-h + ABMIL（两个东西拼起来）

#### 1. UNI2-h —— "看图的眼镜"

- 全称 UNI2-h，是 2024 年 Mahmood 实验室（哈佛）发的**病理基础模型**（foundation model）。
- 类比：就像 CLIP/BERT 之于通用图像/文本，UNI2-h 是专门在**海量病理图**上预训练的视觉模型。
- 它干的事：把一张 WSI（全切片图，几万像素×几万像素的超大图）切成小方块（patch，256×256 像素），每个 patch 编码成一个 **1536 维向量**。
- 我们没自己训练 UNI2-h（太贵），直接用别人预训练好的，**下载数据集时特征已经提好了**——400 张胃癌切片，每张约 1.3 万个 patch，每个 patch 一个 1536 维向量。
- **为什么用它**：它是 2024-2026 病理 AI 的主流编码器（对标 Virchow/UNI），比老论文用的 ResNet18（2018 年 ImageNet 训的）强很多。这是我们能超 SOTA 的关键。

#### 2. ABMIL —— "把一堆 patch 汇总成一个判断"

- 全称 Attention-Based Multiple Instance Learning（注意力多示例学习，Ilse 2018）。
- 问题：一张切片有上万个 patch，但标签是**病人级**的（敏感/不敏感）。怎么从上万 patch 得到一个病人判断？
- ABMIL 的做法：给每个 patch 算一个**注意力权重**（attention），权重高的 patch"更重要"，加权求和成一个病人向量，再分类。
- 好处：① 端到端可训练 ② attention 权重可解释（能看模型关注哪些区域）③ 轻量（CPU 都能跑）。
- 结构（我们的）：`1536 → 256(投影) → attention(128) → 加权求和 → 64 → 2(分类)`，参数量几十万，A100 上一张切片毫秒级。

#### 3. 模型面板的其余部分

- **M5 临床基线**：不用图像，只用临床变量（年龄/性别/Lauren 分型/分期/部位）做逻辑回归。**作用是消融**——证明图像特征比临床强多少。
- **M6 生存**：用 ABMIL 提的图像特征 + Cox 比例风险模型预测生存风险。Cox 是生存分析的经典统计模型（lifelines 库）。
- **Agent（DeepSeek-v3 + 规则编排）**：
  - **DeepSeek-v3-friday**：走美团 Friday API，负责综合写病理报告（直接输出正文，稳定）。
  - **规则编排**：确定性规则判断 M1/M2/M3 模型一致性，定置信度 + IHC 建议（不依赖 LLM 思考，稳定可解释）。
  - 视觉模块（glm-4v-plus）经测试在 overlay 图上区分度差，已移除。
  - Agent **不参与预测**（最终预测仍是 M1），只做：① 规则选可信模型 ② 综合写可 IHC 验证的报告。零指标风险。

## 三、数据集怎么划分

### 数据

- **TCGA-STAD**：The Cancer Genome Atlas 的胃腺癌队列，公开数据。
- 我们用的：**322 个病人**（有完整分子亚型标签的），每人 1 张 H&E 切片。
- 标签来源：cBioPortal 的 PanCancer Atlas 子研究，4 个分子亚型（EBV/MSI/GS/CIN）。
- 标签分布（免疫敏感任务）：正例 82（MSI 56 + EBV 26），负例 240，约 1:3。

### 交叉验证：site-stratified 5-fold × 2 repeat

**关键概念：站点偏差（site bias）**

- TCGA 数据来自全球几十家医院（"站点"）。不同医院的切片染色、扫描仪、人群都不一样。
- 如果随机划分 train/val，**同一医院的切片可能同时出现在 train 和 val**——模型会"认医院"而非"认病灶"，AUC 虚高。这是 Howard 2021 Nature Communications 警示的坑。
- **我们的做法（site-stratified）**：按 TCGA barcode 第 2 段（=医院代码）分组，保证**同一医院的切片要么全在 train，要么全在 val**。这样 val 的 AUC 更接近真实泛化性能。
- 5 折 × 2 次重复 = 10 个 fold。小站点（<8 样本）只进 train 不单独做 val（避免 val 太小 AUC 算不出）。

### 评估指标

- **OOF AUC**（out-of-fold）：每个病人在 val 集里被预测过，汇总所有预测算 AUC。这是最诚实的报法（不是 per-fold 均值，后者偏乐观）。
- **Bootstrap 95% CI**：重采样 1000 次估置信区间，报 [下限, 上限]。
- 次要：AP（平均精度，正例少时比 AUC 更敏感）、C-index（生存模型的 concordance index）。

### 实验设置对比（详细）

**我们做到的（比多数前人严）**：
1. **site-stratified CV**：同医院不跨 train/val（Howard 2021 要求）。Kather/Lee 多用随机 CV，我们更严。
2. **分子特征不进模型**：TMB/突变/甲基化这些和 MSI 同源的分子特征，绝不进输入（会循环论证，AUC 虚高到 0.95+ 但无意义）。多数论文没明确隔离这点。
3. **OOF 报法 + bootstrap CI**：报置信区间，不报乐观的 per-fold 均值。
4. **消融完整**：图像(M1 0.884) vs 临床(M5 0.620) = +0.264，证明图像特征增量。

**我们还没做（前人有的）**：
1. **外部验证**：Kather 在日本 KCCH 队列外部验证（AUC 从 0.81 掉到 0.69）。我们只有 TCGA 内部 CV，可能偏乐观。**这是 IF 8-15 的硬门槛**。
2. **编码器公平对照**：我们用 UNI2-h，前人用 ResNet18/50。AUC 领先部分来自编码器更强，非方法创新。需补 ResNet50 baseline。
3. **全量 patch**：本地用 6000 patch 抽样（省算力），GPU 全量 patch 版本训练中。

### 一句话总结对比

**指标层面已是同任务 SOTA**（M1 0.897、M2 0.906 超 Kather 0.81、Zhang 0.835），且评估更严（site-stratified）。消融清晰：图像(M1 0.897) vs 临床(M5 0.620) = +0.277。模型权重已保存（models/M1-M4.pt）。

## 五、整体 workflow

```
┌─────────────────────────────────────────────────────────────┐
│  原始数据 (TCGA-STAD)                                        │
│  ├─ WSI 切片 → UNI2-h 提特征 → 400 文件 × (N,1536) patch向量 │
│  └─ cBioPortal 临床+分子标签 → clinical.csv (322 病人)       │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  模型面板训练 (site-stratified 5-fold CV)                    │
│  M1 免疫敏感  M2 MSI  M3 EBV  M4 四亚型  [ABMIL, 图像]       │
│  M5 临床基线 [sklearn]   M6 生存 [ABMIL+Cox]                │
│  → 各自 OOF 预测 + 模型权重                                  │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  Agent 编排 (GLM-5.2 + glm-4v-plus, 不改预测)                │
│  1. 规则选可信模型 (M1 vs M2/M3 一致性)                      │
│  2. 视觉提取 TIL 形态证据 (glm-4v-plus 看 overlay)           │
│  3. 综合写病理报告 (GLM-5.2: 多模型+形态+IHC建议)            │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
          最终预测(M1) + 可解释报告(IHC验证锚点)
```

## 六、报告产出（Agent 生成示例）

对每个病人，Agent 产出一份报告，长这样（真实输出节选）：

> **患者**：TCGA-BR-6453，男，54岁，STAD_GS 亚型
> **M1 预测**：免疫不敏感 (prob=0.012)
> **模型一致性**：M1 与 M5 临床模型一致（都不敏感）
> **视觉证据**：TIL 密度高、明显聚集、肿瘤-间质界面浸润
> **冲突**：模型预测与视觉形态存在张力（形态提示免疫活跃）
> **建议**：行 PD-L1 及 MMR/MSI 双重 IHC 验证，排查潜在免疫获益人群

**关键**：报告里的"TIL 密度高/聚集/界面浸润"是医学同学能用 CD3/CD8 IHC 验证的锚点——这就是"可解释、可验证"的价值。
