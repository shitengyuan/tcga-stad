# 胃癌 H&E → MSI 状态预测研究设计 v1

> **一句话定位**:用公开 TCGA-STAD 数据,基于 TIL 空间特征训练 H&E → MSI 预测模型,作为 proof-of-concept,为后续本院新辅助治疗队列研究做方法学铺垫。

---

## §1 研究问题与定位

| 项 | 内容 |
|----|------|
| **核心问题** | 能否仅用诊断 H&E 切片,通过 TIL 量化特征预测胃癌患者的 MSI 状态? |
| **临床意义** | MSI-H 是新辅助治疗方案选择的关键(化疗抵抗 + 免疫敏感),但 IHC/PCR 在基层不普及。AI 提供低成本初筛工具。 |
| **定位** | Proof-of-concept(概念验证);公开数据 demo + 为后续本院新辅助队列研究铺路 |
| **目标期刊** | Front Oncol / Cancer Med / Pathol Oncol Res(IF 3-5) |
| **诚实声明** | 100 例样本量为限制,需在 Discussion 明确报告并设计后续验证 |

### 1.1 临床故事(为什么 MSI 和新辅助治疗强相关)

- **MSI-H 胃癌对传统化疗反应差** — Pietrantonio JCO 2019 meta-analysis(整合 MAGIC/CLASSIC/ITACA-S/ARTIST):MSI-H 患者 5-FU 类围手术期化疗反而生存不获益甚至受害
- **MSI-H 胃癌对免疫治疗高度敏感** — NEONIPIGA(Andre JCO 2023):dMMR/MSI-H 新辅助 nivo+ipi 单独使用,pCR 率 60%+;CheckMate-649、KEYNOTE-585/859 亚组分析均确认 MSI-H 获益
- **临床痛点** — MSI 检测需 IHC(MMR 蛋白)或 PCR(微卫星 panel),基层医院不普及,活检小样本失败率高
- **AI 切入口** — H&E 普遍存在,AI 模型作为零成本初筛,阳性病例再做 IHC/PCR 确认

## §2 数据策略

### 2.1 数据来源

| 数据 | 渠道 | 备注 |
|------|------|------|
| TCGA-STAD WSI(.svs) | GDC Portal + `gdc-client` | 国内需 VPN 或夜间多线程 |
| 临床信息 + MSI/EBV/Lauren 标签 | cBioPortal | 直接表格下载,国内访问良好 |
| Saltz TIL maps(参考标签) | TCIA / Stony Brook Box | 用于结果对比验证 |

### 2.2 样本筛选(目标 N=100)

**纳入标准**(同时满足):
- 有诊断切片(`diagnostic_slide` 字段非空,排除冰冻切片)
- 有 MSI 状态标签(MSI-H / MSI-L / MSS;合并 MSI-L 入 MSS)
- 有 OS 随访 ≥ 12 个月
- **未接受过新辅助治疗**(treatment-naive 队列)
- WSI 质量过 HistoQC 自动质控

**分层富集抽样**(避免极度不平衡):
- **MSI-H 全选**(TCGA-STAD 约 50-70 例)
- **MSS 随机抽 30-50 例**(分层:Lauren 分型 + 性别 + 年龄段匹配)
- **最终目标比例:MSI-H ≈ 25,MSS ≈ 75**(1:3)

### 2.3 ROI 选取策略(降低计算量关键)

- 每例 WSI **5-10 个 ROI**,每个 1024×1024 像素 @ 20×
- 选取方式:**自动选肿瘤区**(暂不依赖病理科)
  - 用 TIAToolbox 或简单 tissue/tumor classifier 筛肿瘤密集区
  - 每例**至少包含 1-2 个肿瘤-基质交界区**(免疫浸润主要发生区域)
- 升级路径:如病理科老师能配合,人工标注 ROI(质量更高,工作量增 20%)

### 2.4 硬盘 / 算力需求(实测核算)

| 资源 | 100 例需求 | 说明 |
|------|-----------|------|
| **硬盘** | 30-50 GB(单文件 200 MB-1.5 GB,平均 ~500 MB) | 建议预留 100 GB 余量 |
| **RAM** | 16 GB 够用 | WSI 按 patch 读取,非全片加载 |
| **GPU 显存** | 8 GB 起步(GTX 1660 / RTX 3060),推荐 12-16 GB | HoVer-Net 推理 |
| **集群?** | ❌ 不需要 | 单工作站完成 |

## §3 技术方案(模型 pipeline)

### 3.1 整体架构

```
WSI (.svs)
   ↓ OpenSlide + HistoQC 质控
ROI patches (1024×1024)
   ↓ HoVer-Net (PanNuke 预训练,零样本推理)
细胞级分割 + 分类(肿瘤/淋巴/基质/坏死/上皮)
   ↓ 特征工程
TIL 密度 + 空间统计特征(每 ROI ~30-50 维)
   ↓ ROI 级特征 → 患者级聚合(均值/最大/分位数)
患者级特征向量
   ↓ 经典 ML 分类器
MSI-H vs MSS 二分类(逻辑回归 / 随机森林 / XGBoost)
```

### 3.2 关键特征清单

| 类别 | 特征 | 工具 |
|------|------|------|
| **基础密度** | TIL 密度、肿瘤细胞密度、基质比例、TIL/肿瘤比 | HoVer-Net 输出统计 |
| **空间统计** | Ripley's K(TIL 聚集度)、最近邻距离、TIL 热点数量 | `pointpats` / `squidpy` |
| **肿瘤-免疫拓扑** | TIL 浸润边界长度、肿瘤巢被 TIL 包绕比例 | 自写脚本 |
| **形态学** | 淋巴细胞核大小/圆度分布 | HoVer-Net 形态特征 |

### 3.3 模型选择(刻意简化)

- **不用深度 MIL**(显存/数据量都吃不消)
- **主模型:逻辑回归 + L1 正则**(可解释、稳定、小样本友好)
- **备选:随机森林、XGBoost**(防 LR 性能不够)
- **交叉验证:5 折分层 CV**,重复 5 次
- **统计上限提醒**:100 例 + 5 折 → 单次 AUC 95% CI 会较宽,要诚实报告

### 3.4 工具栈

| 工具 | 用途 | 备注 |
|------|------|------|
| OpenSlide | WSI 读取 | 必须 |
| HistoQC | WSI 自动质控 | 必须 |
| HoVer-Net + PanNuke 权重 | 细胞分割+分类 | 必须 |
| TIAToolbox | WSI 工具箱(可选 ROI 选取/可视化) | 推荐 |
| CLAM | MIL 框架(本研究暂不用,但需要熟悉) | 备用 |
| CTransPath | 中国团队病理 Transformer encoder | 升级路径 |
| pointpats / squidpy | 空间统计 | 必须 |
| scikit-learn | 经典 ML | 必须 |
| lifelines / scikit-survival | 生存分析(次要终点) | 推荐 |

## §4 统计分析与评估

### 4.1 主要终点
- **AUC**(ROC)及 95% CI(bootstrap 1000 次)
- **敏感度、特异度、PPV、NPV** @ 最佳 Youden 阈值
- 与 Kather 2019 报告的胃癌 AUC(~0.81)对比

### 4.2 次要终点
- 特征重要性排序(L1 稀疏选择 + permutation importance)
- TIL 密度分布在 MSI-H vs MSS 间的差异(箱线图 + Mann-Whitney U)
- 与 Saltz TIL maps 的相关性(验证 TIL 量化合理性)
- (可选)TIL 高低组生存差异 KM 曲线

### 4.3 局限性诚实报告(写进 Limitations)
- 单中心(TCGA-STAD,西方人群为主)
- 小样本(N=100)
- 未在亚洲胃癌队列验证
- ROI 自动选取可能引入选择偏倚
- 未直接评估对治疗响应的预测能力(留给下一篇本院数据论文)

## §7 风险与应对

| 风险 | 概率 | 应对 |
|------|------|------|
| TCGA WSI 国内下载慢 | 高 | `aria2` 多线程 + 夜间挂机 + 分批下载(先 20 例 pilot) |
| HoVer-Net 零样本在 TCGA 表现差 | 中 | Plan B:PanNuke + 少量 TCGA 手工标注微调(~50 ROI) |
| 100 例 AUC 不达预期 | 中 | 改叙事:从"预测模型"改为"探索性相关性研究",报告 effect size |
| MSI 标签不全 | 低 | TCGA-STAD 大部分有 MSI 标签,cBioPortal 一键筛选 |
| CS 同学时间不够 | 中 | W5-9 并行化:用户做样本筛选/文献,CS 同学专注模型 |
| 病理科要求共一 | 低 | 若使用人工 ROI 标注则接受,讨论作者顺序 |
